# Bailout Club

Next.js (App Router) + Tailwind + Supabase + Lucide. Runs on local demo data with no credentials.

```bash
npm install
npm run dev
```

Supabase (optional): copy `.env.example` to `.env.local`, fill both vars, run `supabase/schema.sql`, then use the Demo/Supabase toggle in the nav.

Routes: `/` landing, `/submit` requester flow, `/vault` patron feed, `/hall` leaderboard.
